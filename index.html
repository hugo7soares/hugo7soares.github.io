Consultor Hub

A atividade de um consultor imobiliário, organizada no próprio computador.

O Consultor Hub é uma aplicação de computador (Windows) para gerir contactos, angariações, prospeção, agenda, negócios e finanças de um consultor imobiliário.

Os dados ficam consigo

Toda a informação é guardada numa base de dados cifrada no computador do utilizador. Não existe servidor do Consultor Hub, conta online nem telemetria.

Ligação ao Google Calendar (opcional)

Se o utilizador a ativar, a aplicação cria no Google Calendar um calendário próprio chamado “Consultor Hub” e mantém lá uma cópia dos eventos da agenda, nos dois sentidos. A aplicação só tem acesso aos calendários que ela própria criou; não lê nem altera os restantes calendários do utilizador. A ligação pode ser desfeita a qualquer momento em Definições → Conectores.

In English. Consultor Hub is a Windows desktop app for real estate agents to manage contacts, listings, prospecting, calendar, deals and finances. All data is stored in an encrypted database on the user's own computer; there is no Consultor Hub server. The optional Google Calendar integration creates a dedicated “Consultor Hub” calendar and keeps the app's events in sync with it, using only the calendar.app.created scope (access limited to calendars the app created).
