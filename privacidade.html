Consultor Hub

Política de privacidade

Última atualização: 25 de novembro de 2026

Quem somos

O Consultor Hub é uma aplicação de computador desenvolvida e mantida por Hugo Moutinho Soares (contacto: hugomoutinhosoares@gmail.com).

Onde ficam os dados

Todos os dados introduzidos na aplicação (contactos, imóveis, agenda, negócios, notas, finanças) são guardados apenas no computador do utilizador, numa base de dados cifrada com uma palavra-passe escolhida por ele. Não existe servidor do Consultor Hub: o autor da aplicação não recebe, não vê e não guarda qualquer dado. A aplicação não envia estatísticas de utilização nem telemetria.

Dados do Google

A ligação ao Google Calendar é opcional e só é feita quando o utilizador a ativa e autoriza na página de consentimento do Google.

  • Acesso pedido: apenas a permissão https://www.googleapis.com/auth/calendar.app.created, que permite à aplicação criar um calendário próprio (“Consultor Hub”) e gerir só os calendários e eventos que ela criou. A aplicação não lê nem altera os outros calendários do utilizador.
  • Para que são usados: exclusivamente para sincronizar os eventos da agenda do Consultor Hub com esse calendário, nos dois sentidos. Por omissão, os eventos enviados levam só o tipo (por exemplo, “Visita”) e a hora; nomes e notas só são enviados se o utilizador o ativar.
  • Onde ficam: os eventos recebidos do Google são guardados na base de dados local do utilizador. As credenciais de acesso (token de atualização) ficam no cofre de credenciais do sistema operativo (Gestor de Credenciais do Windows), nunca na base de dados nem em qualquer servidor.
  • Partilha: os dados do Google não são partilhados, vendidos nem transferidos para terceiros, não são usados para publicidade e não são usados para treinar modelos de inteligência artificial.
  • Revogação e eliminação: o utilizador pode desligar a ligação em Definições → Conectores (o acesso é revogado junto do Google e o token apagado do computador) ou em myaccount.google.com/permissions. O calendário “Consultor Hub” pode ser apagado no próprio Google Calendar.

A utilização e transferência de informação recebida das APIs do Google para qualquer outra aplicação cumpre a Google API Services User Data Policy, incluindo os requisitos de Limited Use.

Inteligência artificial

As funções de IA são opcionais e usam um fornecedor escolhido e configurado pelo utilizador. Antes de qualquer envio, a aplicação substitui nomes e dados de contacto por pseudónimos e mostra ao utilizador o texto exato que será enviado, que só segue com a sua confirmação. Os dados obtidos do Google Calendar não são enviados a serviços de IA.

Direitos do utilizador

Como todos os dados estão no computador do utilizador, este pode consultá-los, exportá-los, corrigi-los ou apagá-los a qualquer momento dentro da aplicação. Para qualquer questão sobre privacidade, contacte hugomoutinhosoares@gmail.com.

Alterações

Se esta política mudar, a nova versão é publicada nesta página com a data de atualização.

Summary in English. Consultor Hub is a desktop app; all user data is stored locally in an encrypted database on the user's computer and the developer receives none of it. The optional Google Calendar integration requests only the calendar.app.created scope, used solely to sync the app's own events with a dedicated “Consultor Hub” calendar. Google user data is stored only on the user's computer, the refresh token is kept in the operating system's credential store, and Google user data is never shared, sold, used for advertising or used to train AI models. Users can revoke access in the app or at myaccount.google.com/permissions. Consultor Hub's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
